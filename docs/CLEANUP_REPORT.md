# تقرير تنظيف المستودع

> **الفرع:** `cleanup/documentation-unused-code-20261026`
>
> **النطاق:** إزالة الوثائق القديمة المتعارضة مع الحالة الحالية، وحذف بقايا كود غير مستوردة، مع إبقاء كل ما يدخل في تشغيل الموقع أو القاعدة أو لوحة التحكم.

## ما تم حذفه

- تقارير الجذر القديمة الخاصة بمراحل CMS والـSEO والمكتبة والفيديو ولوحة التحكم وقوائم التسليم والخطط.
- ملفات دخول إدارية قديمة من الجذر، ومنها `ADMIN_ACCESS.md` الذي كان يحتوي بيانات اعتماد مكتوبة داخله. حذف الملف من هذا الفرع لا يلغي ظهوره في تاريخ Git أو في `main`؛ يجب تدوير كلمة مرور الإدارة إذا كانت تلك البيانات استُخدمت فعليًا.
- مجلدات خطط وتقارير تنفيذ صفحات الدول القديمة داخل `docs/`.
- تقارير SEO التي كانت تصف قوائم قديمة من 7 أو 17 دولة.
- `components/LanguageSwitcherExample.tsx` و`components/optimized-image.tsx` لعدم وجود imports خارجية لهما.
- `lib/optimization-utils.ts` و`lib/performance-monitor.ts` و`lib/prefetch-utils.ts` و`lib/useTranslation.tsx` و`lib/use-scroll-restoration.ts` لعدم وجود imports أو routes أو اختبارات تعتمد عليها.
- طبقة `components/country-landings/` و`lib/country-renderers.ts` القديمة؛ جميع صفحات الدول الأربعين تستخدم الآن `CountryLandingEngine` و`CountryUnifiedLanding`، وتم تحديث اختبار المسارات ليتحقق من المحرك المركزي فقط.

## ما لم يتم حذفه

- `supabase/migrations/` لأنها سجل schema وبذور وتشغيل قابل للمراجعة.
- `supabase/rollback/` و`supabase/seeds/` لأنها مطلوبة للاسترجاع أو المقارنة، وليست ملفات واجهة قديمة.
- `db/isolated/` و`scripts/` والاختبارات.
- `components/BlogSection.tsx` لأن `components/admin/BlogManager.tsx` يعتمد على type صادر منه.
- `components/LandingPageVideoStrip.tsx` و`lib/site-stats.ts` و`lib/supabaseClient.ts` لأنها مستخدمة فعليًا في صفحات الدولة والحساب وschema.
- وثائق الحالة الحالية: المعمارية، قاعدة البيانات، لوحة التحكم، الأداء، فهرس التوثيق، سجل التاريخ، وعقود مصادر البيانات.

## فحوص ما قبل/بعد الحذف

- فحص imports قبل حذف كل مجموعة من ملفات الكود.
- فحص مراجع المسارات قبل حذف مجلدات الوثائق.
- `git diff --check` نجح.
- `pnpm build` نجح، ويشمل صفحات الموقع العامة والدول الأربعين ومسارات الإدارة.
- `pnpm exec tsc --noEmit` نجح.
- `pnpm lint` نجح.
- اختبارات الدول والتصميم والبيانات والتعلم والأمن والعقود نجحت بعد التنظيف.
- اختبار SEO للمدونة تم تحديثه ليتحقق من التخزين المؤقت في المستودع الحالي، ثم نجح.
- فحص التوثيق لم يجد إشارات للقوائم القديمة أو المسارات المحذوفة.

اختبار التكامل `test:isolated-triangle` ما زال يفشل في الحالة الحالية لأن اختبارًا قديمًا يتوقع أن تعديل `landing_page_configs` من لوحة الإدارة يغير صفحة السعودية، بينما `CountryLandingEngine` الحالي لا يقرأ هذا المصدر ويعتمد عقد نموذج الدولة المركزي. لم أعدّل سلوك الإنتاج لإخفاء هذا التعارض؛ يلزم قرار منفصل: إعادة ربط محرر landing القديم بالمحرك المركزي أو إيقاف هذا المسار الإداري القديم.

هذا الفرع غير مدمج في `main`، وأي نشر إنتاجي لن يتأثر به حتى تتم مراجعة Pull Request ودمجه صراحة.
