# خطة صفحة هبوط الأرجنتين

## القرار التنفيذي
تُنفذ الأرجنتين داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة باللغة الإسبانية للتعريف والاستهداف.

## المفهوم التصميمي
مفهوم «دفتر الموسيقى»: افتتاحية بإيقاع بصري من خطوط متقطعة، وقسم الأسعار على هيئة شرائط باقات رفيعة متفاوتة السماكة بدل الكروت التقليدية. الأسئلة تفتح داخل نوافذ جانبية صغيرة، والفيديو شريط منخفض الارتفاع قبل Footer حتى لا يزاحم الدعوة الأساسية.

## الهوية
أزرق سماوي `#0284C7`، ذهبي `#F59E0B`، كحلي `#172554`، أزرق باهت `#E0F2FE`، وفحمي `#0F172A`. المدن: بوينس آيرس، قرطبة، روساريو، مندوزا. المنطقة الزمنية: `America/Argentina/Buenos_Aires`. المدن سياق جغرافي فقط ولا توجد مقرات أو فروع أو أماكن تدريس محلية.

## الكلمات المحلية المخصصة
تستهدف الصفحة عبارات عربية خاصة بالأرجنتين: «تحفيظ قرآن أونلاين في الأرجنتين»، «مراجعة القرآن بالعربية في بوينس آيرس»، «تأسيس العربية للناطقين بالعربية في قرطبة»، و«دروس فردية للقرآن في الأرجنتين».

## اللغة المحلية
البطاقة باللغة الإسبانية، وتتضمن تعريفًا بتحفيظ القرآن وتأسيس العربية للناطقين بالعربية، وتعليمًا فرديًا أونلاين، والمدن المختارة، وأن التواصل مع الأكاديمية باللغة العربية.

## الأسعار
سعر Wise بتاريخ 27 سبتمبر 2026: `1 USD = 1,524.75 ARS`. قاعدة الحذف لأسفل: القرآن 22,871 / 42,693 / 64,039 / 83,861 ARS، والعربية 30,495 / 54,891 / 82,336 / 109,782 ARS.

تظهر عبارتا «يوجد باقات مخصصة.» و«خصم 10٪ للأخوات والإحالة». لا تظهر روابط `/quran` أو `/arabic` ولا الدفع أو Checkout أو روابط YouTube ثابتة.
