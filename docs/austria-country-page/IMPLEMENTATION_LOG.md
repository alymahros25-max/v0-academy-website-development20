# سجل تنفيذ صفحة النمسا

## الحالة

تم تنفيذ صفحة النمسا داخل الفرع الموحد `feat/country-pages-23`. لم يُنشأ فرع مستقل، ولم تُدمج الصفحة في `main`، ولم تُنشر Production.

## التنفيذ

الصفحة عربية بالكامل والتواصل مع الأكاديمية باللغة العربية. أضيفت بطاقة ألمانية قصيرة بعنوان `Online-Koranlernen und Arabisch-Grundlagen in Österreich` تتضمن تحفيظ القرآن، تأسيس العربية، الخدمة الفردية، المدن المختارة، وكلمات الاستهداف الطبيعية، مع تثبيت أن التواصل يتم بالعربية.

استخدمت الصفحة تصميم «نوتة موسيقية»: Hero بخطوط ناعمة، خدمتان كمسارين لحنيين، سلم أسعار من أربع درجات، نافذة فيديو باختيار الموضوع، وفواصل إيقاعية للأسئلة. الهوية مستقلة عن جنوب أفريقيا والصين وإيطاليا وروسيا والنرويج: بنفسجي ملكي، وردي باهت، ذهبي، وعاجي.

المدن: فيينا، غراتس، لينتس، وسالزبورغ. المنطقة الزمنية: `Europe/Vienna`.

## الأسعار

تم استخدام سعر Wise المتوسط بتاريخ 24 سبتمبر 2026: 1 USD = 0.8780 EUR، مع حذف الكسور لأسفل. أسعار القرآن: 13، 24، 36، 48 €. أسعار العربية: 17، 31، 47، 63 €. تمت مزامنة الأسعار في إعداد الصفحة وMigration وOffer Schema.

## التكامل

أضيفت Migration 031 بالـslug المعزول `austria`، وتشمل المحتوى والأسعار والأسئلة والروابط والهوية والمدن والمنطقة الزمنية. أضيف `/austria` إلى Sitemap وقائمة الدول المشتركة وClient Providers isolation.

يستخدم الفيديو مصدر `classroom_videos` عبر `getPublishedClassroomVideos`، مع اختيار موضوع القرآن أو العربية أو محتوى الأكاديمية، والصور المصغرة أولًا وفتح المشغل عند النقر. يحتوي Footer على الرئيسية والألعاب والمسابقات والمكتبة والتواصل والخصوصية والشروط، وقائمة جميع الدول. لا توجد روابط `/quran` أو `/arabic` ولا عناصر دفع أو شراء.

## نتائج الفحص

نجحت `git diff --check` وESLint وTypeScript وNext.js production build. استجاب المسار المحلي `/austria` بحالة HTTP 200. ظهر Title وCanonical خاصان بالنمسا، والبطاقة الألمانية، والأسعار باليورو، وSchema من WebPage وEducationalOrganization وCourse وOffer وFAQPage. لم تظهر روابط البرنامجين العامة أو عبارات الدفع والشراء، وظهر رابط النمسا في Footer.

## قاعدة الدمج والنشر

تبقى جميع التغييرات داخل `feat/country-pages-23`. تضاف الدول التالية إلى الفرع نفسه دون دمج أو نشر حتى اكتمال الدول الـ23 واعتماد المجموعة.
