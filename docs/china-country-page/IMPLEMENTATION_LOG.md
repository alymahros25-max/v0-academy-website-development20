# سجل تنفيذ صفحة الصين

## الحالة

تم تنفيذ صفحة الصين على فرع `feat/china-country-page` فقط. لم تُدمج في `main` ولم تُنشر Production.

## الملفات المنفذة

- `app/china/page.tsx`: الصفحة العربية الأساسية، البطاقة الصينية، البرامج، المدن، الأسعار، FAQ، CTA وFooter.
- `app/china/china-goal-stepper.tsx`: دفتر الأهداف بثلاث خطوات وكشف فيديو تدريجي.
- `app/china/china-price-reveal.tsx`: لوحة الأسعار التبادلية بين القرآن والعربية.
- `lib/china-landing-config.ts`: fallback مستقل للصين.
- `supabase/migrations/027_seed_china_country_page.sql`: بيانات الصين المعزولة.
- `components/layout/country-pages-section.tsx`: إضافة رابط الصين إلى القائمة المشتركة.
- `components/client-providers.tsx`: عزل صفحة الصين عن غلاف الموقع العام.
- `app/sitemap.ts`: إضافة `/china` إلى Sitemap.

## قرارات الالتزام

تبقى الصفحة عربية، وتظهر الصينية في بطاقة محلية قصيرة فقط. لا يوجد دعم صيني أو فرع محلي مدعى. لا يوجد زر دفع. الأسعار باليوان، ويُفضّل مصدر Supabase عند توفره مع fallback محلي.

الفيديوهات تُجلب من `classroom_videos` عبر `getPublishedClassroomVideos`، ويُعرض أول ثلاثة مقاطع منشورة في كشف تدريجي من ثلاث خطوات. لا تُنسخ روابط YouTube يدويًا.

## الفحوص الأولية

- `git diff --check`: ناجح.
- ESLint للملفات الجديدة والمعدلة: ناجح قبل تعديل ربط الأسعار الديناميكي، ويعاد بعده.
- TypeScript: ناجح قبل تعديل ربط الأسعار الديناميكي، ويعاد بعده.
- Next.js Build والمسار `/china`: نُفذا بنجاح قبل تعديل ربط الأسعار الديناميكي، ويعادان بعده.
- اختبار محلي أولي لـ`/china`: `HTTP 200`.
- ظهرت بطاقة الصينية، قيم `CNY`، Schema، وقسم روابط الدول.

## الخطوة التالية

إعادة تشغيل الفحوص بعد ربط لوحة الأسعار ببيانات Supabase، ثم اختبار جميع مسارات الدول محليًا، ومراجعة diff، ورفع الفرع إلى GitHub فقط.


## نتائج الفحص النهائي

بعد ربط لوحة الأسعار ببيانات المنطقة، نجحت فحوص `git diff --check` وESLint وTypeScript وNext.js Build. استجاب مسار `/china` محليًا بحالة `HTTP 200`، واستجابت جميع مسارات الدول الـ19 المختبرة بحالة `HTTP 200`.

ظهرت في HTML الصفحة علامات العنوان الصيني، و`CNY`، وبيانات `application/ld+json`، وقسم «صفحاتنا حسب الدولة». أضيف رابط الصين إلى القائمة المشتركة وإلى Sitemap، وأضيف المسار إلى عزل غلاف الموقع العام.
