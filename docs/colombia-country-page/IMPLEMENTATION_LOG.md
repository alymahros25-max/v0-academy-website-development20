# سجل تنفيذ صفحة كولومبيا

تم تنفيذ كولومبيا داخل `feat/country-pages-23` دون فرع جديد أو دمج أو نشر. الصفحة عربية بالكامل، وبطاقة التعريف بالإسبانية، والتواصل بالعربية. التصميم دفتر أسئلة: سؤال افتتاحي، بطاقات اختيار المسار، أسعار على هيئة إجابات، أسئلة مختصرة، وبطاقة فيديو «اسأل قبل أن تبدأ» من مصدر `classroom_videos`. أضيفت Migration 035، Sitemap، Client Providers، وقائمة الدول المشتركة.

سعر Wise بتاريخ 26 سبتمبر 2026: `1 USD = 3,291 COP`. قاعدة الحذف لأسفل: القرآن 49,000 / 92,000 / 138,000 / 181,000 COP، والعربية 65,000 / 118,000 / 177,000 / 236,000 COP. المدن بوغوتا وميديلين وكالي وبارانكيا سياق جغرافي فقط دون مقرات أو فروع أو أماكن تدريس محلية.

لا توجد روابط `/quran` أو `/arabic` أو أزرار دفع أو Checkout أو روابط YouTube ثابتة داخل الصفحة. الأسعار والتعريف والأسئلة والـFooter باللغة العربية، والبطاقة الإسبانية للتعريف والاستهداف فقط.
