# خطة إنشاء صفحة هبوط كولومبيا

## القرار التنفيذي

تُنفذ كولومبيا على `feat/country-pages-23` فقط دون فرع جديد أو دمج أو نشر. الصفحة عربية بالكامل، والتواصل باللغة العربية، مع بطاقة إسبانية قصيرة للتعريف والاستهداف.

## الهوية والهيكل

تستخدم الصفحة فكرة «دفتر الأسئلة»: افتتاحية بسؤال مباشر، ثم بطاقات يختار منها الزائر الإجابة التي تصف هدفه، ثم الأسعار كإجابات مختصرة، والأسئلة كاستبيان متدرج. الألوان: أزرق ملكي `#123B8A`، أصفر `#F4C542`، مرجاني `#E96B55`، وخلفية `#F7F9FC`. الفيديو يظهر داخل بطاقة «اسأل قبل أن تبدأ» من `classroom_videos`.
