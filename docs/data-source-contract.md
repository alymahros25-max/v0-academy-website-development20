# عقد مصادر البيانات

## القاعدة العامة

قاعدة Supabase هي مصدر الحقيقة للمحتوى المنشور والإداري في الإنتاج. تستخدم واجهات الإدارة `supabaseAdmin` داخل الخادم فقط بعد التحقق من جلسة الإدارة، ولا يجوز تمرير `SUPABASE_SERVICE_ROLE_KEY` إلى Client Components أو المتصفح.

## خريطة المجالات

| المجال | مصدر الإنتاج | مسار القراءة العام | سياسة fallback |
|---|---|---|---|
| صفحات الدول، الباقات، FAQ، الروابط، الثيم، المدن والتوقيت | جداول `site_areas` و`area_*` | `/api/public/areas/[slug]` أو Server Components عبر `getAreaLandingData` | fallback لنفس الدولة فقط من `lib/country-static-fallback.ts` و`lib/country-fallbacks.ts` |
| مقاطع الحصص | `classroom_videos` | `/api/classroom-videos` | لا يعرض المسار العام بيانات غير منشورة؛ تعرض الصفحة قسمًا اختياريًا فارغًا عند تعذر القراءة |
| مقالات المدونة | `blog_posts` | `/api/blog` وصفحة `/blog/[slug]` | المقال الثابت المقابل فقط عند توفره، وليس مقالًا من دولة أو slug آخر |
| الصفحات القانونية | `legal_pages` | `/api/public/legal` | النص الثابت المضمن في الصفحة عند غياب السجل |
| الثيم والودجات | `theme_customizations` و`widget_configs` | `/api/public/theme` و`/api/public/widgets` | إعداد افتراضي آمن ومعلن في الاستجابة عبر `source` حيث ينطبق |
| المعلمون والمراجعات والإعدادات العامة | مستودعات `admin_content` وملفات JSON | `/api/public/teachers` و`/api/public/reviews` و`/api/public/packages` | JSON محلي للتطوير أو عند عدم توفر التخزين، ولا يُستخدم كبديل لنجاح كتابة الإدارة |
| إعدادات السعودية والإمارات | `landing_page_configs` | Server Components وواجهات CMS | إعداد typed لنفس slug فقط |

## قواعد تمنع الالتباس

يجب تسجيل fallback على أنه وضع degraded في السجلات الخادمية، وعدم اعتباره نجاح اتصال بقاعدة البيانات. عمليات الكتابة الإدارية لا تستخدم fallback صامتًا: عند غياب قاعدة البيانات أو فشل الحفظ تعود استجابة خطأ قابلة لإعادة المحاولة.

تُفلتر القراءة العامة في قاعدة البيانات على `is_active = true` أو `is_published = true` بحسب المجال. أما الجداول الإدارية مثل `admin_content` و`cms_users` و`cms_permissions` و`site_settings` فتبقى بلا سياسات قراءة عامة، ويكون الوصول إليها عبر APIs خادمية محمية بجلسة الإدارة.

لا يجوز دمج بيانات fallback من بلد مختلف. يجب أن يطابق `slug` المطلوب سجل fallback نفسه، كما يجب أن تطابق عملة الباقة عملة المنطقة. عند إضافة مجال جديد، يجب تحديد مصدره العام، وسياسة fallback، ومسار الإدارة في هذا الملف قبل استخدامه في الواجهة.

## المراقبة

يفحص `/api/health` اتصال الجداول الأساسية (`site_areas` و`blog_posts` و`classroom_videos`) دون كشف رسائل قاعدة البيانات أو الأسرار. الحالة `ok` تعني أن الاستعلامات الأساسية نجحت، و`degraded` تعني أن الموقع يحتاج مراجعة تشغيلية؛ لا تعرض الاستجابة تفاصيل SQL للمستخدم.
