# خطة إنشاء صفحة هبوط الدنمارك

## القرار التنفيذي

تُنفذ الدنمارك داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية بالكامل، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة باللغة الدنماركية للتعريف والاستهداف.

## الهوية والهيكل

تستخدم الصفحة فكرة «المفكرة العملية»: افتتاحية هادئة بملاحظات قصيرة، ثم شبكة برامج غير متناظرة، ثم جدول أسعار مفكك لا يتبع شبكة أربع بطاقات متساوية، وأسئلة في شبكة صغيرة، ولوحة فيديو غير متماثلة بثلاثة أحجام. الألوان: أحمر داكن `#8B1E3F`، أبيض `#FFFFFF`، رمادي فاتح `#F1F3F5`، ورمادي نصي `#263238`.

## البيانات والأسعار

المدن: كوبنهاغن، آرهوس، أودنسه، ألبورغ. المنطقة الزمنية: Europe/Copenhagen. المدن سياق جغرافي فقط ولا توجد مقرات أو فروع أو أماكن تدريس محلية.

سعر Wise بتاريخ 26 سبتمبر 2026: `1 USD = 6.56231 DKK`. قاعدة الحذف لأسفل: القرآن 98 / 183 / 275 / 360 DKK، والعربية 131 / 236 / 354 / 472 DKK.

تظهر عبارتا «يوجد باقات مخصصة.» و«خصم 10٪ للأخوات والإحالة». لا تظهر روابط `/quran` أو `/arabic` ولا الدفع أو Checkout أو روابط YouTube ثابتة.
