# خطة إنشاء صفحة هبوط فنلندا

## القرار التنفيذي

تُنفذ فنلندا داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية بالكامل، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة باللغة الفنلندية للتعريف والاستهداف.

## فكرة التصميم الجديدة

تعتمد الصفحة مفهوم «مساحة التركيز»: واجهة هادئة واسعة قليلة الزخرفة، مع أسئلة اختيارية بصيغة نعم/لا تتوسع إلى إجابة عملية. الأسعار لا تظهر في بطاقات، بل كأرقام كبيرة داخل مساحات بيضاء منفصلة مع خط رفيع يربط كل مستوى بالبرنامج. هذا يميز فنلندا عن المسارات والبطاقات والخرائط والخطوط الزمنية السابقة.

## الهوية

الألوان: أبيض ثلجي `#F8FAFC`، أزرق جليدي `#B9D9E8`، كحلي هادئ `#183B56`، وأصفر خافت `#E7D878`. المدن: هلسنكي، إسبو، تامبيري، توركو. المنطقة الزمنية: Europe/Helsinki. المدن سياق جغرافي فقط ولا توجد مقرات أو فروع أو أماكن تدريس محلية.

تظهر عبارتا «يوجد باقات مخصصة.» و«خصم 10٪ للأخوات والإحالة». لا تظهر روابط `/quran` أو `/arabic` ولا الدفع أو Checkout أو روابط YouTube ثابتة.
