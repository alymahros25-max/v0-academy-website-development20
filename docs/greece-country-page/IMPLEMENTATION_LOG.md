# سجل تنفيذ صفحة اليونان

تم تنفيذ اليونان داخل `feat/country-pages-23` دون فرع جديد أو دمج أو نشر. الصفحة عربية بالكامل، وبطاقة التعريف باللغة اليونانية، والتواصل باللغة العربية.

## الهوية والتفرد

- التصميم: «مخطوطة مراحل» بخط زمني من اليمين إلى اليسار.
- الأسعار: درجات مدرّج غير متساوية، وليست شبكة بطاقات أربع.
- الأسئلة: ألواح متتابعة داخل صفحة مستقلة.
- الفيديو: خط زمني بنقاط تشغيل وصور مصغرة من `classroom_videos`.
- الألوان: أزرق بحر، أبيض، برونزي، ورمادي حجر.

## التكامل

أضيفت Migration 038، ومسار Sitemap، وعزل Client Providers، ورابط اليونان إلى المصدر المشترك لقائمة الدول. لا توجد روابط `/quran` أو `/arabic` أو أزرار دفع أو Checkout أو روابط YouTube ثابتة.

## الأسعار

سعر الحساب المستخدم من Wise هو `1 USD = 0.877848 EUR` بتاريخ 26 سبتمبر 2026 مع حذف الكسور لأسفل: القرآن 13/24/36/48، والعربية 17/31/47/63.

## الاختبارات

نجحت ESLint وTypeScript وNext.js production build وفحص المحتوى. تم اختبار المسار محليًا مع المسارات السابقة دون دمج أو نشر Production.
