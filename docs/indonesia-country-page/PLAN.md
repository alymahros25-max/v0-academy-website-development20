# خطة صفحة هبوط إندونيسيا

## القرار التنفيذي
تُنفذ إندونيسيا داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة باللغة الإندونيسية للتعريف والاستهداف.

## الفكرة التصميمية الجديدة
مفهوم «دفتر الجزيرة»: افتتاحية تتكون من جزر مترابطة تمثل خطوات التعلم. قسم البرامج والأسعار عبارة عن مسار أفقي قابل للتمرير اليدوي مع مؤشر تقدم، وليس تبويبات أو شبكة بطاقات. كل محطة تعرض باقة واحدة كبيرة مع حركة هادئة قابلة للتعطيل. الأسئلة تتحرك من أسفل عند اختيار السؤال، والفيديو شريط أفقي قابل للسحب بعد قسم المدن.

## الهوية
أخضر جوز الهند `#176B5B`، برتقالي مشمس `#F28C28`، أزرق بحري `#145DA0`، كريمي `#FFF8ED`، وفحمي `#20312D`. المدن: جاكرتا، سورابايا، باندونغ، ميدان. المنطقة الزمنية: `Asia/Jakarta`. المدن سياق جغرافي فقط ولا توجد مقرات أو فروع أو أماكن تدريس محلية.

## اللغة المحلية
البطاقة باللغة الإندونيسية، وتتضمن تعريفًا بتحفيظ القرآن وتأسيس العربية للناطقين بالعربية، وتعليمًا فرديًا أونلاين، والمدن المختارة، وأن التواصل مع الأكاديمية باللغة العربية.
