# سجل تنفيذ صفحة إيطاليا

## الحالة

تم تنفيذ صفحة إيطاليا داخل الفرع الموحد `feat/country-pages-23`. لم يُنشأ فرع مستقل لإيطاليا، ولم تُدمج الصفحة في `main`، ولم تُنشر Production.

## الملفات المنفذة

- `app/italy/page.tsx`: الصفحة العربية، SEO، Schema، البرامج، المدن، FAQ، CTA، والفوتر المستقل.
- `app/italy/italy-journey.tsx`: رحلة المحطات الأربع مع فيديوهات المصدر المشترك.
- `app/italy/italy-monthly-tickets.tsx`: تذاكر الباقات الشهرية باليورو بطريقة عرض مستقلة.
- `lib/italy-landing-config.ts`: الهوية، الأسعار، المدن، التوقيت، البطاقة الإيطالية، والأسئلة.
- `supabase/migrations/028_seed_italy_country_page.sql`: بيانات إيطاليا المعزولة.
- `components/layout/country-pages-section.tsx`: إضافة رابط إيطاليا إلى قائمة جميع الدول.
- `components/client-providers.tsx`: عزل مسار إيطاليا عن غلاف الموقع الرئيسي.
- `app/sitemap.ts`: إضافة `/italy` إلى Sitemap.

## قرارات الصفحة

الصفحة عربية والتواصل مع الأكاديمية باللغة العربية. البطاقة المحلية باللغة الإيطالية وتشرح تحفيظ القرآن وتأسيس العربية أونلاين. الأسعار باليورو والرمز `€`، وقيمها:

- القرآن: 13، 24، 36، 47.
- العربية: 17، 31، 47، 62.

لا تظهر روابط `/quran` أو `/arabic` في Footer إيطاليا أو بطاقات البرامج. لا يظهر دفع أو شراء أو Checkout.

تستخدم الصفحة هوية إيطالية مستقلة: طوبي داكن، عاجي، زيتوني، أزرق حبر، وزعفراني. عرض الأسعار على هيئة تذاكر رحلة شهرية، وعرض الفيديو داخل المحطات الأربع، وFAQ في لوحات مقابلة.

- ESLint للملفات الجديدة والمشتركة.
- TypeScript `tsc --noEmit`.

- استجابة `/italy` المحلية بحالة HTTP 200.
- Title خاص بإيطاليا.

- بطاقة إيطالية محلية ظاهرة.

- عدم وجود روابط مباشرة إلى `/quran` أو `/arabic` في Footer إيطاليا.

## قاعدة الدمج والنشر

يبقى Commit إيطاليا داخل `feat/country-pages-23`. تُضاف الدول التالية إلى الفرع نفسه. لا يتم الدمج إلى `main` أو النشر Production قبل اكتمال الدول الـ23 واعتماد المجموعة.
