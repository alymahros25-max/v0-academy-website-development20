# سجل تنفيذ صفحة نيوزيلندا

تم تنفيذ نيوزيلندا داخل `feat/country-pages-23` دون فرع جديد أو دمج أو نشر. الصفحة عربية بالكامل، وبطاقة التعريف باللغة الإنجليزية، والتواصل باللغة العربية.

## التفرد

- مفهوم «دفتر مسارات» بمسارين بصريين يلتقيان عند اختيار البرنامج.
- بطاقات الباقات قابلة للطي بدل شبكة البطاقات المتساوية.
- الأسئلة معروضة كأبواب صغيرة متتابعة.
- الفيديوهات بطاقات قابلة للفتح يظهر وصفها قبل الصورة.
- لوحة الألوان: أخضر سرخسي، أزرق محيطي، رملي، وأبيض دافئ.

## التكامل

أضيفت Migration 039، ومسار Sitemap، وعزل Client Providers، ورابط نيوزيلندا إلى المصدر المشترك لقائمة الدول. لا توجد روابط `/quran` أو `/arabic` أو أزرار دفع أو Checkout أو روابط YouTube ثابتة.

## الأسعار

سعر Wise المستخدم بتاريخ 26 سبتمبر 2026 هو `1 USD = 1.76538 NZD`. بعد حذف الكسور لأسفل: القرآن 26/49/74/97 NZD، والعربية 35/63/95/127 NZD.

## الاختبارات

نجحت ESLint وTypeScript وNext.js production build. استجابت `/new-zealand` و`/greece` و`/denmark` محليًا بحالة HTTP 200، وظهر العنوان والـcanonical والبطاقة الإنجليزية والأسعار وقائمة الدول، دون روابط البرنامجين في Footer.
