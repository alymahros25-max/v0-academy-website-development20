# خطة إنشاء صفحة هبوط نيوزيلندا

## القرار التنفيذي

تُنفذ نيوزيلندا داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية بالكامل، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة باللغة الإنجليزية للتعريف والاستهداف.

## فكرة التفرد

تستخدم الصفحة مفهوم «دفتر مسارات»: يبدأ الزائر من مسارين بصريين منفصلين، مسار القرآن ومسار العربية، ثم يلتقيان في نقطة اختيار واحدة. الباقات تُعرض في بطاقات قابلة للطي، والأسئلة في أبواب صغيرة، والفيديوهات في بطاقات قابلة للفتح يظهر وصفها قبل الصورة. لا تُستخدم شبكة أربع بطاقات ولا خط زمني ولا مدرّج.

تظهر عبارتا «يوجد باقات مخصصة.» و«خصم 10٪ للأخوات والإحالة». لا تظهر روابط `/quran` أو `/arabic` ولا الدفع أو Checkout أو روابط YouTube ثابتة.
