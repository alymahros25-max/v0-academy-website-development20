# خطة صفحة هبوط نيجيريا

## القرار التنفيذي
تُنفذ نيجيريا داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية والتواصل مع الأكاديمية بالعربية، مع بطاقة قصيرة بالإنجليزية للتعريف والاستهداف.

## المفهوم التصميمي
مفهوم «دفتر قائمة تشغيل»: افتتاحية تشبه مشغلًا مرتبًا بعناوين مرقمة، والأسعار تظهر كقائمة تشغيل مرئية لا كشبكة كروت، وكل سؤال يفتح بزر مستقل. الفيديوهات تظهر كقائمة تشغيل بعد قسم الأسعار مع رقم ترتيب ومدة البيانات المتاحة.

## الهوية
أخضر عميق `#064E3B`، أبيض `#FFFFFF`، برتقالي `#F97316`، رمادي دافئ `#F3F4F6`، وفحمي `#111827`. المدن: لاغوس، أبوجا، كانو، وبورت هاركورت. المنطقة الزمنية: `Africa/Lagos`. المدن سياق جغرافي فقط، ولا توجد مقرات أو فروع أو أماكن تدريس محلية.

## اللغة المحلية والكلمات
البطاقة بالإنجليزية، وتذكر تحفيظ القرآن وتأسيس العربية للطلاب الناطقين بالعربية والتعليم الفردي أونلاين والتواصل بالعربية. الكلمات العربية المخصصة: تحفيظ القرآن أونلاين في نيجيريا، مراجعة القرآن بالعربية في لاغوس، تأسيس العربية للناطقين بالعربية في أبوجا، ودروس قرآن فردية في نيجيريا.
