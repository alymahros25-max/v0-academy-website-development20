# سجل تنفيذ صفحة النرويج

## الحالة

تم تنفيذ صفحة النرويج داخل الفرع الموحد `feat/country-pages-23`. لم يُنشأ فرع مستقل، ولم تُدمج الصفحة في `main`، ولم تُنشر Production.

## التنفيذ

الصفحة عربية بالكامل والتواصل مع الأكاديمية باللغة العربية. أضيفت بطاقة نرويجية قصيرة بعنوان `Quran på nett og grunnleggende arabisk i Norge` تتضمن تحفيظ القرآن، تأسيس العربية، الخدمة الفردية، المدن المختارة، وكلمات الاستهداف الطبيعية، مع تثبيت أن التواصل يتم بالعربية.

استخدمت الصفحة تصميم «دفتر يوميات هادئ»: افتتاحية ضبابية قليلة العناصر، لوحة مرونة وتوقيت، لوحة فيديو رئيسية مع مقاطع صغيرة، مقياس أسعار أفقي، وأسئلة عربية قصيرة متباعدة. الهوية مستقلة عن روسيا والصين وإيطاليا: أزرق فيوردي، أبيض ثلجي، رمادي ضبابي، أخضر صنوبر، وعنبر خافت.

المدن: أوسلو، بيرغن، تروندهايم، وستافنجر. المنطقة الزمنية: `Europe/Oslo`.

## الأسعار

تم استخدام سعر Wise المتوسط بتاريخ 24 سبتمبر 2026: 1 USD = 9.479 NOK، مع حذف الكسور لأسفل. أسعار القرآن: 142، 265، 398، 521 kr. أسعار العربية: 189، 341، 511، 682 kr. تمت مزامنة الأسعار في إعداد الصفحة وMigration وOffer Schema.

## التكامل

أضيفت Migration 030 بالـslug المعزول `norway`، وتشمل المحتوى والأسعار والأسئلة والروابط والهوية والمدن والمنطقة الزمنية. أضيف `/norway` إلى Sitemap وقائمة الدول المشتركة وClient Providers isolation.

يستخدم الفيديو مصدر `classroom_videos` عبر `getPublishedClassroomVideos`، مع الصور المصغرة أولًا وفتح المشغل عند النقر. يحتوي Footer على الرئيسية والألعاب والمسابقات والمكتبة والتواصل والخصوصية والشروط، وقائمة جميع الدول. لا توجد روابط `/quran` أو `/arabic`.

## نتائج الفحص

نجحت `git diff --check` وESLint وTypeScript وNext.js production build. استجاب المسار المحلي `/norway` بحالة HTTP 200. ظهر Title وCanonical خاصان بالنرويج، والبطاقة النرويجية، والأسعار المحلية، وSchema من WebPage وEducationalOrganization وCourse وOffer وFAQPage. لم تظهر روابط البرنامجين العامة، وظهر رابط النرويج في Footer.

## قاعدة الدمج والنشر

بقيت جميع التغييرات داخل `feat/country-pages-23`. تضاف الدول التالية إلى الفرع نفسه دون دمج أو نشر حتى اكتمال الدول الـ23 واعتماد المجموعة.
