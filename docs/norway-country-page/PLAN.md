# خطة إنشاء صفحة هبوط النرويج

## الحالة

مواصفة تنفيذية لصفحة النرويج داخل الفرع الموحد `feat/country-pages-23`. لا يُنشأ فرع جديد، ولا يتم الدمج في `main` أو النشر في Production.

## القواعد المعتمدة

الصفحة عربية بالكامل، والتواصل مع الأكاديمية باللغة العربية. تظهر بطاقة قصيرة باللغة النرويجية للتعريف والاستهداف فقط، ولا تعلن دعمًا أو تواصلًا باللغة النرويجية. البطاقة تذكر اسم النرويج والأكاديمية، تحفيظ القرآن، تأسيس العربية، الخدمة الفردية، المدن المختارة، وكلمات البحث النرويجية الطبيعية.

لا تظهر روابط `/quran` أو `/arabic` في Footer أو بطاقات البرامج. لا يظهر الدفع أو الشراء أو Checkout. تظهر عبارة «يوجد باقات مخصصة» و«خصم 10٪ للأخوات والإحالة» فقط.

## الهوية والتفرد

تُعامل الصفحة كدفتر يوميات هادئ: افتتاحية ضبابية قليلة العناصر، خطوط رفيعة ومساحات واسعة، مقياس أسعار أفقي، وأسئلة عربية قصيرة متباعدة على فواصل ورقية. لا تُستخدم طريقة روسيا الرأسية أو الصين التبادلية أو إيطاليا ذات التذاكر.

لوحة الألوان: أزرق فيوردي `#234B5A`، أبيض ثلجي `#F4F8F7`، رمادي ضبابي `#C7D5D8`، أخضر صنوبر هادئ `#58756B`، وعنبر خافت `#C5965A`.

## البيانات المحلية

المسار `/norway`، الدولة Norway، الرمز NO، العملة NOK، والرمز المحلي `kr`. المدن: أوسلو، بيرغن، تروندهايم، وستافنجر. المنطقة الزمنية: `Europe/Oslo`.

البطاقة النرويجية:

`Quran på nett og grunnleggende arabisk i Norge. Al-Hafiz Academy tilbyr individuelle nettleksjoner i koranmemorering og grunnleggende arabisk. Oslo, Bergen, Trondheim og Stavanger brukes som geografisk kontekst for siden. Koranstudium og arabiskundervisning for arabisktalende elever. Kontakt med akademiet foregår på arabisk.`

## ترتيب الصفحة

افتتاحية ضبابية بعنوان عربي هادئ عن بناء عادة للقرآن والعربية، بطاقة النرويج المحلية، قسم المرونة والتوقيت، لوحة الفيديو الرئيسية مع مقاطع صغيرة أسفلها، برنامجا القرآن والعربية، قسم المدن والتوقيت، مقياس الأسعار الأفقي، أسئلة عربية قصيرة متباعدة، CTA للحصة التجريبية، ثم Footer مستقل وقسم جميع الدول.

## الفيديو

الموضع بعد فقرة المرونة. المصدر الوحيد `classroom_videos` عبر `getPublishedClassroomVideos`. يعرض الفيديو الرئيسي أولًا ثم ثلاثة مقاطع صغيرة، مع الصور المصغرة أولًا وفتح المشغل عند النقر. عند خلو المصدر يظهر نص تعريفي دون مساحة فارغة.

## Footer وSEO وSupabase

يحتوي Footer على `/` و`/games` و`/library` والتواصل والخصوصية والشروط، وقائمة جميع الدول من المصدر المشترك. تضاف النرويج إلى القائمة المشتركة، Sitemap، وعزل Client Providers.

يُنشأ Title وDescription وCanonical وOpen Graph وTwitter وWebPage وEducationalOrganization وCourse وOffer وFAQ Schema. تُنشأ Migration 030 مع slug مستقل `norway` وتشمل المحتوى والأسعار والأسئلة والروابط والهوية والمدن والمنطقة الزمنية.

## الاختبارات

يُفحص diff وESLint وTypeScript وBuild وHTTP وTitle وCanonical وSchema والأسعار وقائمة الدول ومصدر الفيديو وعدم وجود روابط البرامج العامة ونظافة الفرع. تبقى كل التغييرات في `feat/country-pages-23`.
