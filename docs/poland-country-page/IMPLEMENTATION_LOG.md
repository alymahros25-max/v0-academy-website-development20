# سجل تنفيذ صفحة بولندا

## نطاق التنفيذ

أُضيفت صفحة `/poland` داخل الفرع `feat/country-pages-23-4` فقط، دون فرع مستقل أو دمج أو نشر. لم تُجرَ أي تغييرات على Supabase أو أي قاعدة بيانات في هذه المراجعة، كما أن Sub-base خارج النطاق بناءً على توجيه المستخدم.

## التحقق من المحتوى وSEO

- الصفحة عربية أولًا، وبطاقة التعريف باللغة البولندية مخصصة للتعريف والاستهداف، مع تثبيت أن الدراسة والتواصل بالعربية ولا توجد منشأة أو فرع أو مكان تدريس محلي.
- تم التحقق من Title وMeta Description وCanonical وOpen Graph وTwitter وJSON-LD الذي يتضمن WebPage وEducationalOrganization وCourse وOffer وFAQPage.
- تم التحقق من وجود كلمات عربية مخصصة للدولة، ومدن وارسو وكراكوف وفروتسواف وغدانسك كسياق جغرافي فقط.
- تم التحقق من أن الأسعار تستخدم الزلوتي البولندي، وأن محتوى الفيديو يأتي من `classroom_videos`، وأن Footer الدول وSitemap موجودان.
- لا تحتوي الصفحة على روابط مباشرة إلى `/quran` أو `/arabic` أو Checkout، ولا على روابط YouTube ثابتة.
- تمت إضافة `hreflang` لـ`ar` و`x-default` إلى Metadata في هذه المراجعة.

## التحقق التقني

Migration الخاصة بالدولة موجودة من التنفيذ السابق فقط، ولم تُطبَّق أو تُعدّل قاعدة البيانات هنا. اجتاز الفرع فحوص ESLint وTypeScript وProduction Build في بيئة الاختبار السابقة، ويجب إعادة تشغيلها بعد الدمج مع `main`.
