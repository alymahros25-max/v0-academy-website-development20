# خطة صفحة هبوط بولندا

## القرار التنفيذي
تُنفذ بولندا داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة باللغة البولندية للتعريف والاستهداف.

## المفهوم التصميمي
مفهوم «دفتر الحلول»: تبدأ الصفحة بسؤال عملي ثم تقدم جوابًا مرئيًا في الافتتاحية. قسم الأسعار عبارة عن كروت حلول مرقمة، كل كرت يشرح عدد الحصص وإيقاعها بدل الملصقات أو الأشرعة أو الشرائح. قسم FAQ هو المركز الرئيسي بصيغة سؤال ثم حل موسع، والفيديوهات مرتبطة بالأسئلة وتفتح من داخل الإجابة.

## الهوية
قرمزي `#B91C1C`، كحلي `#172554`، أبيض ورقي `#F8FAFC`، وردي فاتح `#FEE2E2`، وفحمي `#111827`. المدن: وارسو، كراكوف، فروتسواف، غدانسك. المنطقة الزمنية: `Europe/Warsaw`. المدن سياق جغرافي فقط ولا توجد مقرات أو فروع أو أماكن تدريس محلية.

## الكلمات المحلية المخصصة
تستهدف الصفحة العربية عبارات خاصة ببولندا: «مدرسة فردية لتحفيظ القرآن في بولندا»، «مراجعة القرآن بالعربية في وارسو»، «تأسيس العربية للناطقين بالعربية في كراكوف»، و«دروس قرآن أونلاين في بولندا». لا تستخدم عناوين أو عبارات الأسعار المميزة للدول الأخرى.

## اللغة المحلية
البطاقة باللغة البولندية، وتتضمن تعريفًا بتحفيظ القرآن وتأسيس العربية للناطقين بالعربية، وتعليمًا فرديًا أونلاين، والمدن المختارة، وأن التواصل مع الأكاديمية باللغة العربية.

## الأسعار
سعر Wise بتاريخ 27 سبتمبر 2026: `1 USD = 3.838 PLN`. قاعدة الحذف لأسفل: القرآن 57 / 107 / 161 / 211 PLN، والعربية 76 / 138 / 207 / 276 PLN.

تظهر عبارتا «يوجد باقات مخصصة.» و«خصم 10٪ للأخوات والإحالة». لا تظهر روابط `/quran` أو `/arabic` ولا الدفع أو Checkout أو روابط YouTube ثابتة.
