# خطة صفحة هبوط البرتغال

## القرار التنفيذي
تُنفذ البرتغال داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة باللغة البرتغالية للتعريف والاستهداف.

## الفكرة التصميمية الجديدة
مفهوم «المفكرة البحرية»: افتتاحية موجية متدرجة تشبه صفحة رحلة، وقسم الأسعار في أشرعة متتابعة تتحرك بصريًا من اليمين إلى اليسار دون تبويبات أو شبكة تقليدية. الأسئلة كمرافئ منفصلة يختار الزائر منها مرفأ واحدًا، والفيديو الرئيسي ثابت بعد الأسعار مع اقتباس وصفي قصير مأخوذ من عنوان الفيديو فقط.
