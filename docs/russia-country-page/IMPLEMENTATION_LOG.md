# سجل تنفيذ صفحة روسيا

## الحالة

تم تنفيذ صفحة روسيا داخل الفرع الموحد `feat/country-pages-23`. لم يُنشأ فرع مستقل، ولم تُدمج الصفحة في `main`، ولم تُنشر Production.

## التنفيذ

تستخدم الصفحة العربية غلافًا قطبيًا واسعًا، بطاقة روسية قصيرة، شريط فيديو أفقيًا ببطاقات جانبية، عرض برنامجين داخل الصفحة، سياق المدن والتوقيت، شريط أسعار رأسيًا، وفواصل أسئلة متتابعة. الهوية مستقلة عن الموقع الرئيسي وعن جنوب أفريقيا والصين وإيطاليا: أزرق ليلي، جليدي، فضي، نحاسي، وكحلي فاتح.

أضيفت بطاقة باللغة الروسية بعنوان `Коран онлайн и основы арабского языка в России`. البطاقة تتضمن تحفيظ القرآن، تأسيس العربية، الخدمة الفردية، المدن المختارة، وعبارة أن التواصل مع الأكاديمية باللغة العربية. لم تُعلن البطاقة دعمًا روسيًا.

الأسعار بالروبل الروسي: القرآن 1278، 2387، 3580، 4688؛ والعربية 1705، 3069، 4603، 6138. اعتمد الحساب على 1 USD = 85.25 RUB بتاريخ 24 سبتمبر 2026 وفق سعر Wise المتوسط، مع حذف الكسور لأسفل.

أضيفت Migration رقم 029 بالـslug المعزول `russia`، وتشمل المحتوى والأسعار والأسئلة والروابط والهوية والمدن والمنطقة الزمنية. أضيف مسار روسيا إلى Sitemap، وقائمة الدول المشتركة، وعزل Client Providers.

## الفيديو وFooter

يستخدم شريط روسيا مصدر `classroom_videos` عبر `getPublishedClassroomVideos`، ويعرض الصور المصغرة أولًا ويفتح المشغل عند النقر. يحتوي Footer على الرئيسية والألعاب والمسابقات والمكتبة والتواصل والخصوصية والشروط، وقائمة جميع الدول من المصدر المشترك. لا توجد روابط `/quran` أو `/arabic`.

## نتائج الفحص

نجحت `git diff --check` وESLint وTypeScript وNext.js production build. استجاب المسار المحلي `/russia` بحالة HTTP 200. ظهر Title وCanonical خاصان بروسيا، وظهرت البطاقة الروسية، وأسعار الروبل، وSchema من أنواع WebPage وEducationalOrganization وCourse وFAQPage. لم تظهر روابط البرنامجين العامة، وظهر رابط روسيا في Footer، وأضيف المسار إلى Sitemap.

## قاعدة الدمج والنشر

بقيت كل التغييرات داخل `feat/country-pages-23`. تُضاف الدول التالية إلى الفرع نفسه، ولا يحدث الدمج إلى `main` أو النشر Production قبل اكتمال الدول الـ23 واعتماد المجموعة.
