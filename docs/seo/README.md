# مركز SEO لأكاديمية الحافظ المتميز

هذا المجلد يجمع مخرجات البحث والتقسيم المتعلقة بتحسين الظهور، مع فصل واضح بين الموقع العام وصفحات الدول.

## الملفات

| الملف | الوظيفة |
|---|---|
| [خريطة الكلمات المفتاحية](./خريطة-الكلمات-المفتاحية-للدول-والصفحات-العامة.md) | ملكية الكلمات لكل صفحة، الكلمات السبع للدول، وقواعد منع التداخل |
| [خطة الموقع العام](../خطة-90-يوم-SEO-وتسويق-أكاديمية-الحافظ-المتميز.md) | خطة الصفحة الرئيسية والبرامج والمدونة والفيديوهات والألعاب |
| [خطة صفحات الدول](../خطة-90-يوم-صفحات-الدول-السبع.md) | خطة تنفيذ مستقلة للصفحات الإقليمية للدول السبع |

## قاعدة الملكية

- الكلمات غير الجغرافية تملكها الصفحة الرئيسية أو صفحة البرنامج المناسبة.
- الكلمات التي تحتوي على دولة أو مدينة أو عملة أو منطقة زمنية تملكها صفحة الدولة المقابلة.
- لا تنشأ صفحة مدينة مستقلة في المرحلة الحالية.
- لا تستخدم صفحات الدول كلمات الألعاب أو الفيديوهات ككلماتها الأساسية.
- أي كلمة جديدة تظهر في Search Console تسجل أولًا في خريطة الكلمات قبل إضافتها إلى صفحة.
