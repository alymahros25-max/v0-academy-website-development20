## 1. قاعدة الفصل

الكلمة العامة تذهب إلى الصفحة العامة المناسبة. الكلمة التي تحتوي على دولة أو مدينة أو عملة أو منطقة زمنية تذهب إلى صفحة الدولة المقابلة.

| نوع البحث | الصفحة المالكة | أمثلة |
|---|---|---|
| خدمة بلا موقع جغرافي | `/quran` أو `/arabic` | تحفيظ قرآن أون لاين، تأسيس عربي للأطفال أون لاين |
| اسم الأكاديمية أو التسجيل العام | `/` أو `/contact` | أكاديمية تحفيظ قرآن، حصة تجريبية تحفيظ قرآن |
| معلم أو معلمة | `/teachers` مع رابط البرنامج | محفظ قرآن أون لاين، معلم لغة عربية أون لاين |
| ألعاب ومسابقات | `/games` | ألعاب حروف عربية، ألعاب قرآن وتجويد |
| فيديو وطريقة التعليم | `/classroom-moments` | فيديو تعليم التجويد، حصص قرآن أون لاين |
| دولة أو مدينة أو عملة | صفحة الدولة | تحفيظ قرآن أون لاين في السعودية، معلم قرآن في لندن |

**لا نضع اسم دولة أو مدينة أو عملة في عنوان أو وصف الصفحة الرئيسية أو صفحة البرنامج بوصفه استهدافًا أساسيًا.** يجوز ذكر نطاق الخدمة بصورة عامة في نص تعريفي، لكن الاستعلام المحلي الكامل يبقى لصفحة الدولة.

## 10. الكلمات التي لا ننشئ لها صفحات إضافية حاليًا

لا ننشئ صفحة مستقلة لكل مدينة مثل `/riyadh` أو `/london` في المرحلة الحالية. تُذكر المدن داخل صفحة الدولة فقط، لأن إنشاء صفحات متشابهة دون خدمة أو محتوى خاص قد يؤدي إلى صفحات ضعيفة وتنافس داخلي.

كذلك لا نضع كلمات الألعاب أو الفيديوهات ككلمات أساسية في صفحات الدول. يمكن وضع رابط إلى `/games` أو `/classroom-moments` عندما يكون مفيدًا للزائر، لكن ملكية الكلمة تبقى للصفحة المتخصصة.

## 11. طريقة اعتماد كلمة جديدة

قبل إضافة أي كلمة إلى صفحة، نجيب عن الأسئلة التالية:

1. هل تحتوي الكلمة على دولة أو مدينة أو عملة؟ إذا نعم، تذهب إلى صفحة الدولة.
2. هل نية الباحث هي تحفيظ القرآن أم تأسيس العربية أم مشاهدة فيديو أم لعب؟ نختار الصفحة المطابقة للنية.
3. هل توجد كلمة مشابهة مملوكة بالفعل لصفحة أخرى؟ إذا نعم، نضيفها كصيغة ثانوية فقط أو نرفضها.
4. هل تقدم الأكاديمية ما تعد به الكلمة فعلًا؟ لا نضيف «فرع» أو «معلم داخل المدينة» دون دليل.
5. هل ظهرت الكلمة في Search Console أو Keyword Planner أو بحث فعلي؟ نسجل مصدرها وحجمها قبل اعتمادها.
