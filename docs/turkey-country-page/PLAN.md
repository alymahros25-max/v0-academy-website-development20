# خطة صفحة هبوط تركيا

## القرار التنفيذي
تُنفذ تركيا داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة باللغة التركية للتعريف والاستهداف.

## الفكرة التصميمية الجديدة
مفهوم «دفتر التبويبات»: يبدأ الزائر بتبويبين واضحين مستقلين، القرآن والعربية، وكل تبويب يغيّر نص المسار والأسئلة والأسعار داخل الصفحة دون فتح صفحات برامج عامة. قسم الأسعار يظهر كتذاكر/طوابع رحلة متدرجة وغير متساوية، وليس شبكة أربع بطاقات. الفيديو يأتي في تبويبين مستقلين بعد البرامج ومن مصدر `classroom_videos`، وتظهر الأسئلة حسب المسار المختار.

## الهوية
تركواز `#0F766E`، قرمزي `#B4233C`، نحاسي `#B7793F`، عاجي `#FFF9F0`، ورمادي حبر `#262626`. المدن: إسطنبول، أنقرة، إزمير، بورصة. المنطقة الزمنية: `Europe/Istanbul`. المدن سياق جغرافي فقط ولا توجد مقرات أو فروع أو أماكن تدريس محلية.

## اللغة المحلية
البطاقة باللغة التركية، وتتضمن تعريفًا بتحفيظ القرآن وتأسيس العربية للناطقين بالعربية، وتعليمًا فرديًا أونلاين، والمدن المختارة، وأن التواصل مع الأكاديمية باللغة العربية.

## الأسعار
سعر Wise بتاريخ 26 سبتمبر 2026: `1 USD = 48.95 TRY`. قاعدة الحذف لأسفل: القرآن 734 / 1370 / 2055 / 2692 TRY، والعربية 979 / 1762 / 2643 / 3524 TRY.

تظهر عبارتا «يوجد باقات مخصصة.» و«خصم 10٪ للأخوات والإحالة». لا تظهر روابط `/quran` أو `/arabic` ولا الدفع أو Checkout أو روابط YouTube ثابتة.

## قبول الصفحة
يجب نجاح ESLint وTypeScript وProduction Build، ومراجعة وجود `/turkey` في القائمة المشتركة وSitemap وعزل Client Providers، وتطابق الأسعار في الواجهة وSchema وMigration، وعدم وجود عبارات تنفيذ أو وعود أو روابط البرامج العامة.
