# خطة إنشاء صفحة هبوط فنزويلا

## القرار التنفيذي

تُنفذ فنزويلا داخل `feat/country-pages-23` فقط، دون فرع مستقل أو دمج أو نشر. الصفحة عربية بالكامل، والتواصل مع الأكاديمية باللغة العربية، وتظهر بطاقة قصيرة بالإسبانية للتعريف والاستهداف.

## الهوية والهيكل

تستخدم الصفحة فكرة «ألبوم الصور»: غلاف بصورة بصرية مجردة وسطر عربي واحد، ثم بطاقة برنامج مركزية وبطاقتان جانبيتان، ثم الأسعار على هيئة شرائط، والأسئلة أسفل كل صورة/موضوع. لوحة الألوان: أزرق سماوي `#118AB2`، أصفر دافئ `#FFD166`، أبيض `#FFFFFF`، وخط داكن `#17324D`.

## البيانات والأسعار

المدن: كاراكاس، ماراكايبو، فالنسيا، باركيسيميتو. المنطقة الزمنية: America/Caracas (UTC−04:00). المدن سياق جغرافي فقط ولا توجد مقرات أو فروع أو أماكن تدريس محلية.

سعر Wise بتاريخ 26 سبتمبر 2026: `1 USD = 855.94 VES`. قاعدة الحذف لأسفل: القرآن 12,839 / 23,966 / 35,949 / 47,076 VES، والعربية 17,118 / 30,813 / 46,220 / 61,627 VES.

تظهر عبارتا «يوجد باقات مخصصة.» و«خصم 10٪ للأخوات والإحالة». لا تظهر روابط `/quran` أو `/arabic` ولا الدفع أو Checkout أو روابط YouTube ثابتة.
